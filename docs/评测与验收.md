# 评测与验收

## 同时看计划、执行和图片

1. 原始模型是否听懂：原模型与 SFT 的原始计划，对照人工审核标签评分。
2. 后端是否安全执行：结构合法计划的接受/拒绝、实际设置与工具调用；后端接受不代表模型语义正确。
3. 图片是否达到要求：实际作用、自然度、误改和失败案例。

不能只看 JSON 格式，也不能把门禁后的正确率当作模型本身的理解能力。

## 指令与状态指标

| 项目 | 检查方式 |
| --- | --- |
| 格式合法率 | JSON Schema、类型、有限数值、重复工具等 |
| 工具选择 | 正确操作集合；多操作和漏操作分别计数 |
| 参数正确 | 使用已冻结档位/标签；不声称某个小数是唯一审美答案 |
| 约束遵循 | “只/不/保留”是否正确，是否越权修改其他工具 |
| 多轮更新 | 当前操作正确，未涉及设置不变 |
| 撤销/重置 | 单项关闭、undo历史与reset初始状态分别验证 |
| 澄清 | 不支持或指代不清时，是否避免错误执行 |
| 结构校验 | 缺字段、未知工具、重复工具、越界参数等拒绝原因；结构接受率与原始计划正确率分开报告 |

明确启用、停用也是状态更新，不能只比操作名称而忽略 enabled。所有指标带样本数、图片/人物数、分母和阶段。

## 实际图像检查

- 瘦脸：方向与局部作用是否合理，下巴/耳部/背景是否受不期望影响。
- 大眼：是否产生可见变化，是否不对称、牵动眉毛或出现边缘畸变。
- 祛痘：局部修复是否正确，是否误伤痣/纹理，漏修与误修分别记录。
- 磨皮：平滑是否过强，是否损失纹理或影响眼唇/头发。
- 全流程：关闭工具时是否确实不调用；没有开启的工具不被擅自加入。
- 目标区域外差异要结合形变作用域解释。直接 JPEG 像素差包含编解码因素；建议使用可复查的无损中间结果，不以非零差异一概判断越权。
- 关键点/分割和规则分可能有自身误差，不能自己定义标签又用同一启发式分数证明质量。
- 保存少量可查看的原图/结果/局部对比和解释；不能只展示最好看的成功例。

## 对比要求

相同原图、指令、历史、接口、工具版本、档位、后端门禁、视觉预处理与解码；只改变基座/adapter。原模型与 SFT 均使用相同冻结测试，不按测试分数挑模型。

按图片/人物汇总，必要时对这些单位重采样。测试太小时如实称探索性结果，不预填显著性或改善幅度。

失败、拒绝、空输出、超时均保留并明确计分，不能从分母中无声剔除。

## 展示与材料

网页可展示指令、前后图片、实际执行项目与程度、跳过原因、历史及撤销。技术细节放调试区，正常用户流程用熟悉语言。

结果报告写清继承了哪些开源工具、自己实现了哪些 Agent/状态/数据/训练/评测工作。准备和代码阅读不写作已完成微调、完整产品或上线成效。
